# Personal Portfolio Website

Full stack portfolio built during the Full Stack Development Internship at ALKJ Technologies.

- Front end: HTML5, CSS3 (Flexbox / Grid), JavaScript (Fetch API)
- Back end: Node.js, Express.js, MongoDB (Mongoose)

## Run locally
1. `cd backend && npm install && npm start`   (set MONGO_URI in .env, or leave empty to store in messages.json)
2. Open `frontend/index.html` with a local server (e.g. VS Code Live Server).
